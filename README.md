# 💬 ChatApp – Real-Time UI/UX Chat Design

📌 A sleek and modern chat interface built using **Figma** and prototyped in **Webflow**. Inspired by Discord and Slack, ChatApp focuses on real-time messaging, dark/light modes, and responsive layouts.

---

## 🎯 Overview
- Design Goal: Modern real-time messaging app UI
- Platform: Mobile + Web
- Tools: Figma (UI/UX), Webflow (Interactive Prototype)

---

## 🌟 Features
- Clean user dashboard with chat list
- Interactive states (hover, active, notifications)

---

## 🛠️ Tech & Tools
- `Figma` for layout, components, and color systems
- `Webflow` for interactions and preview animations
